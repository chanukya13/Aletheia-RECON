# Visual research desk redesign

The first job is comprehension: explain that RECON investigates historical remedies against inspectable sources and modern experiments. This is a design hypothesis, not a measured usability result.

## Direction

Use a quiet application shell, a botanical still life, one featured investigation and a visible source-to-experiment sequence. The opening question is onion versus leek in Bald’s eyesalve. The illustration represents the topic; it is explicitly not source or experimental evidence. Actual passages, observations and reported units remain separate.

Palette: fog `#f4f6f8`, paper `#ffffff`, ink `#172c34`, slate `#53636c`, deep teal `#125e52`, soft teal `#e4f0eb`. Amber marks uncertainty, never a confidence score. Locally hosted Manrope serves controls and headings; Georgia remains appropriate for original quotations. Left-align reading and controls; constrain prose measure. Keep the main research action prominent.

Desktop navigation is a persistent labeled rail. Phone navigation opens from a labeled menu. Four research steps mark locations, not completed work. Source inspection stays directly available. Candidate support becomes a visible trail with exact contributions on demand. Measured outcomes use bars computed from selected published observations, retaining units, strain, source inspection and arithmetic. Advanced scenario controls and raw diagnostics remain accessible through disclosures.

## Guidance consulted

- [UI/UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): accessibility, labeled adaptive navigation, typography, touch targets, focus and feedback. Automatic research-lab portfolio and calculator recommendations were rejected; the disclosure search found no suitable database match. Composition is an explicit project decision.
- [Frontend design skill](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md): subject-specific direction, restrained motion, concise copy and screenshot critique.
- [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/): hierarchy, clarity and accessible interaction.
- [IBM progressive disclosure guidance](https://www.ibm.com/docs/en/technical-content?topic=practices-progressive-disclosure): show essentials for the current task and reveal details when needed.
- Bundled React and full-story verification skills: query caching, immutable scientific state, component boundaries and browser/API/data checks.

## Assets

`apps/web/src/public/images/onion-leek-study.webp` was generated using the built-in image tool and encoded as WebP without changing composition. Prompt: an editorial museum-studio still life of an onion bulb, a cut leek and an empty glass petri dish on a pale sage-gray surface, realistic botanical detail and soft daylight; no text, charts, historical documents, cultures, labels or experimental results. It is illustrative only.

Manrope is local under SIL OFL 1.1, with its license beside the font. No runtime remote font/image request is required. No research source, policy, review status, measurement or benchmark changes.

## Verification

Retain before screenshots. Build, type-check, lint, validate data, and run scientific tests. Exercise navigation, source inspection, exclusions, strain changes, unavailable contrasts, saves, exports and offline replay. Check 320/390/768/1024/1440 widths, phone landscape, keyboard navigation, reduced motion, enlarged text, accessibility, console and HTTP errors. Preserve failed attempts and fix causes. Recheck the public URL after deployment; free-hosting limitations remain explicit.
